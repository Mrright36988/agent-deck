# agent-deck 插件验证（临时窗口）

这个窗口只用来测试。测试 hook 只对这个目录里的会话生效：这里的会话一旦触发审批、提问或停下，hook 会先等 20 秒，再自动作答，相当于模拟你在 deck 里点了按钮。
**请在这 20 秒里留意插件界面有什么变化。**

## Claude Code（右侧插件，新开一个会话）

先确认插件底部的权限模式是 Ask before edits，不是 auto 或 bypass。

1. 审批：发送「用 Bash 执行 touch probe_perm.txt」
   - 前 20 秒，插件里有没有弹出审批框？
   - 20 秒后，命令是否自动执行了（目录里出现 probe_perm.txt）？
2. 选项题：发送「请调用 AskUserQuestion 工具问我一个单选题：选 A 还是 B」
   - 前 20 秒，插件里有没有出现选项卡片？
   - 20 秒后，Claude 有没有说你选了 A？
3. 停下后的文字回复：发送「STOPTEST 只回复 OK」
   - 它回完 OK 后会再等 20 秒，然后收到一条模拟的 deck 回复，并接着回答（开头带 [DECK]）。
   - 这条模拟回复在插件里显示成什么样：像你自己发的消息，还是一条 hook 提示？

## Codex（同一窗口打开 Codex 插件，新开会话，模式用默认的 Agent，不要选 Full access）

4. 审批：发送「运行命令 curl -sI https://example.com」
   - 前 20 秒，有没有弹出审批框？
   - 20 秒后，是否自动放行并返回了结果？（如果它根本没要审批、直接执行了，记下来就行。）
5. 停下后的文字回复：发送「STOPTEST 只回复 OK」
   - 回完 OK 再过 20 秒，它有没有自动收到回复并继续回答？显示成什么样？

做完后回到 workspace 窗口告诉 Claude。剩下 3 项要从那边发起：跨会话消息、跳转 URI、codex queue。到时候你回到这个窗口看效果就行。
